# ASuperTAB Wiki

Official documentation website for **ASuperTAB v1.0.0** by **Klioh_**.

## Publish with GitHub Pages

1. Upload the contents of this repository to GitHub.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select your main branch and `/ (root)`.
5. Save. GitHub will publish `index.html` as the wiki homepage.

## Theme

The site uses an Aqua + Yellow + White palette and is fully responsive for desktop and mobile.

- `assets/css/style.css` — site styling

- `examples/*.yml` — default ASuperTAB configuration examples extracted from v1.0.0
- `.nojekyll` — prevents GitHub Pages from applying Jekyll processing
